# HomeStock QA — 7 November 2026

Environment: isolated jsdom application DOM, real application scripts and localStorage fallback. No production household data or credentials used. This is not physical-device/browser visual QA.

## Results

- Created 90 products through the editor: all 15 categories in Pantry, Fridge, Freezer, Toilet, Shower and General. Checked quantity, location, price, expiry and desired stock persistence.
- Edited saved stock, price and notes.
- Canceled inventory deletion and verified no change.
- Injected a rejected inventory deletion; verified error, preserved product and usable controls.
- Deleted all 90 products through editor confirmation; double-clicked confirmation; verified no stranded editor and preserved expense history.
- Deleted and restored an expense; verified current route remains unchanged.
- Purchased, archived, undid and removed a shopping item; verified route preservation.
- Saved a barcode-prefilled product through the shared editor; verified expiry, voice and desired-quantity controls exist.
- Navigation DOM test and ten existing logic/regression suites passed (including sync deletion tombstones and decoder fixtures).

No additional production-code defect was reproduced in this matrix after the v4.3.60 deletion changes.

## Repeat

With jsdom installed outside the repository or available in NODE_PATH:

    NODE_PATH=/path/to/node_modules node tools/full-qa.cjs
    NODE_PATH=/path/to/node_modules node tools/page-navigation-test.cjs

Run from the repository root. The script exits nonzero on failure and disposes its isolated DOM after success.
