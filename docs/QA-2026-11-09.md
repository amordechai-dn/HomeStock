# Two-profile QA — 9 November 2026

Application baseline: v4.5.0. All tests used disposable storage under qa.invalid, with no production repository requests or access to the user's browser storage. Existing real inventory was not read, edited or deleted.

## Matrix — all passed

Four independent runs of tools/full-qa.cjs:

- Aviraz with localStorage fallback.
- Sigal with localStorage fallback.
- Aviraz with the IndexedDB implementation exercised through fake-indexeddb.
- Sigal with the IndexedDB implementation exercised through fake-indexeddb.

Each run creates and deletes 90 disposable products: every one of the 15 categories in all six locations. Total: 360 additions and 360 deletions, plus shopping and barcode test records.

Before each run, the *other* household receives protected fixture inventory, shopping, expenses, barcode metadata and an image. Its complete serialized snapshot is compared after the active household's tests. Every comparison passed unchanged.

Checked flows: quantities/prices/expiry/desired stock, edits, deletion cancellation, double deletion clicks, simulated storage failure and recovery, expense preservation, expense delete/undo, shopping purchase review/archive/undo/delete, barcode-prefilled shared editor, and current-page preservation.

Additional passing suites cover Hebrew profile labels, remembered selection, legacy household preservation, isolated sync credentials, package accounting, financial rules, GitHub conflict/tombstone logic, decoder fixtures, Hebrew voice parsing, dates, dropdowns, service-worker precache, update deferral and navigation animation cancellation.

No additional production-code defect reproduced. Only tests/documentation changed in this QA task.

## Repeat

From repository root with jsdom and fake-indexeddb available:

    QA_PROFILE=aviraz NODE_PATH=/path/to/node_modules node tools/full-qa.cjs
    QA_PROFILE=sigal NODE_PATH=/path/to/node_modules node tools/full-qa.cjs
    QA_PROFILE=aviraz QA_STORAGE=indexeddb NODE_PATH=/path/to/node_modules node tools/full-qa.cjs
    QA_PROFILE=sigal QA_STORAGE=indexeddb NODE_PATH=/path/to/node_modules node tools/full-qa.cjs

## Limits

DOM-based checks and simulated IndexedDB do not replace actual browser/device testing. Samsung camera focus, microphone, touch gestures, responsive visuals, installed PWA update delivery and real push-notification delivery were not physically verified. Mock sync passing does not establish that either user's devices are connected live.
